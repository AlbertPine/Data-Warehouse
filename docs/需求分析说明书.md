# 需求分析说明书

电商商家与用户运营数仓用于复盘历史活动。商家运营可以查询某天的活跃和购买情况、比较商品类目与品牌，并分别查看后续互动与训练样本的复购表现。数据工程人员负责核验这些指标能否从原始记录重算。

## 业务背景

2025 年全国网上零售额为 159,722 亿元，同比增长 8.6%。这组数据说明行业规模。项目使用的是阿里云天池发布的历史竞赛数据，指标范围以该数据集为准。 [国家统计局 2025 年网上零售额](https://www.stats.gov.cn/sj/zxfbhjd/202601/t20260119_1962323.html) · [阿里云天池数据集](https://tianchi.aliyun.com/dataset/42)

淘宝开放平台的《双11保障商家白皮书》把流量、收藏、加购、下单和支付列为商品经营分析的观察环节。IJCAI 竞赛关注促销吸引的新买家在半年内是否再次向同一商家购买。前者说明商家为什么要逐项观察商品表现，后者说明为什么同一商家的后续行为值得跟踪。项目据此选择三类运营场景。 [淘宝开放平台 生意参谋](https://developer.alibaba.com/docs/doc.htm?articleId=103513&docType=1&treeId=47) · [IJCAI 复购买家预测竞赛说明](https://ijcai-15.org/repeat-buyers-prediction-competition/)

天猫在 2025 年商家大会公布了品牌会员运营支持措施，提到通过搜索、推荐和购物车增加会员触达，以促进复购。项目把促销后的回访与复购作为两个观察问题，分别由行为日志与训练标签提供证据。 [阿里巴巴集团 天猫商家大会](https://www.alibabagroup.com/en-US/document-1843369564457402368)

| 使用者 | 使用场景 | 后续动作 |
|---|---|---|
| 商家运营 | 比较商家的活跃与购买覆盖，查看单个商家的日趋势 | 选择值得继续复盘的商家和日期 |
| 商品运营 | 查看类目和品牌的行为量及购买行为量 | 选出需要继续核查的类目、品牌组合 |
| 用户运营 | 查看年龄和性别分群的活跃情况，同商家回访率及样本复购比例 | 检查哪些人群或观察期值得进一步分析 |
| 数据工程人员 | 按商家和日期重算指标，检查来源、发布状态和重跑结果 | 确认数据可以发布，定位指标差异或失败阶段 |

## 功能需求

| 编号 | 需求 | 验收方式 |
|---|---|---|
| F01 | 商家运营总览展示完整分析期的去重活跃和购买人数，日报支持按商家与月日筛选 | 在日报选择商家 `3828`、月日 `0511`，看板显示 184 位活跃用户，应用层查询返回 272 条行为和 70 位购买用户 |
| F02 | 类目与品牌对比展示行为量和购买行为量，支持按类目、品牌、月日缩小范围 | 按筛选条件与 `tmall_ads.category_brand_day` 核对，两项分别为行为记录与购买行为记录的计数 |
| F03 | 用户分群支持年龄组、性别和月日筛选 | 优先按单日读各分组的去重人数，跨日合计解释为日活跃人次 |
| F04 | 回访与复购分别展示并说明分子、分母和观察窗口 | 商家 `3828` 在 `0511` 的 7 日回访为 32/184。全训练标签中正标签为 15,952/260,864 |
| F05 | 支持运营看板查询、明细回查及批次运行记录查询 | 使用相同的商家、月日条件从 DWD 重算 ADS 指标，使用源行号回到 ODS |

## 非功能需求

| 编号 | 要求 | 验收方式 |
|---|---|---|
| N01 | 数据质量可核验 | 校验输入文件大小、SHA-256 和结构。全量 54,925,330 条原始行为等于 54,925,284 条有效行为加 46 条隔离记录 |
| N02 | 查询权限和运行权限分离 | `bi_reader` 可查询 `tmall_ads`，读原始层应被拒绝。仓库维护由独立账号执行 |
| N03 | 可重跑、可定位失败 | 同一已发布批次复用并复核，写入后失败的批次保留运行记录。Airflow 可查询运行日志 |
| N04 | 汇总可复用、查询结果一致 | 对全部商家从明细或商家用户日表重算区间活跃用户，逐商家核对一致。记录同机同口径的耗时以便对比 |
| N05 | 本机部署可复现 | 使用 Compose 启动组件并独立检查容器、发布视图和看板，数据卷保留发布数据及看板配置 |

## 数据可行性与应用范围

行为日志提供用户、商家、商品、类目、品牌、月日和动作，支持去重人数、购买行为和回访窗口分析。用户画像包含年龄组、性别等编码。复购训练文件提供已标注的用户与商家组合，支持计算样本正标签占比。日期源字段只有 MMDD，金额、支付状态和营销成本字段缺失。交付范围为历史行为的离线查询与复盘。复购结果只适用于有标签样本，商品和品牌以脱敏编号展示。详细边界见[数据源与指标字典](数据源与指标字典.md)。

需求分析基于公开行业资料、竞赛任务和数据可用性。需求安排先核对业务问题与数据条件，再设计事实粒度、维度和指标。 [Kimball 业务需求和源数据摸底](https://www.kimballgroup.com/data-warehouse-business-intelligence-resources/kimball-techniques/dimensional-modeling-techniques/business-requirements-data-realities/)
