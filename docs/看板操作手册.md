# 看板操作手册

商家和用户运营人员可以在 Superset 查询历史活动的活跃情况、商品行为及回访复购。浏览器入口为 [Superset 登录页](http://127.0.0.1:18088/login/)。使用管理员提供的 Superset 账号登录。

| 看板 | 图表 | 筛选与用途 |
|---|---|---|
| [商家运营总览](http://127.0.0.1:18088/superset/dashboard/tmall-merchants/) | 商家活跃用户与购买用户、按日查看商家活跃 | 第一张图按商家筛选完整分析期去重人数。日报按商家和月日查看趋势 |
| [类目与品牌对比](http://127.0.0.1:18088/superset/dashboard/tmall-category/) | 类目与品牌行为分布 | 按类目、品牌、月日筛选。柱高表示全部行为或购买行为的记录数 |
| [用户分群与样本复购](http://127.0.0.1:18088/superset/dashboard/tmall-users/) | 用户分群活跃、标签样本复购比例、商家 7 日回访率 | 分群图可筛月日、年龄组、性别，默认月日为 `1111`。样本复购可按商家筛选。回访可按起算月日和商家筛选 |

## 查商家 3828 在 0511 的日活

1. 打开「商家运营总览」。
2. 在筛选区找到名称以「按日查看商家活跃」开头的商家编号 `merchant_key` 和月日 `mmdd`。
3. 选 `3828` 和 `0511`，应用筛选。悬停查看柱形提示，活跃人数应为 **184**。
4. 需要看整段趋势时清除日期筛选。查看其他商家时替换商家编号再应用。

筛选器作用于其名称对应的图表。若同时查看日报与回访，分别选择两张图的筛选值。若要继续核查，交给数据维护者的条件是商家编号 `3828` 和月日 `0511`，应用层还可核对 272 条行为与 70 位购买用户。

## 读数时核对统计范围

- 商家总览的全期和日报对应不同日期范围。日报合并多个商家时，人数显示为商家日活跃人次。
- 用户分群跨日合计为日活跃人次。要查看某日去重活跃人数，选择一个月日。
- `0511` 的商家 7 日回访应查同商家后续一周的行为，示例为 32/184，约 17.39%。最后可用起算日为 `1104`。
- 标签样本复购的总体值是 15,952/260,864，约 6.12%。这是全训练标签的样本比例，选择商家后分子和分母一起变化。

字段和计算规则见[数据源与指标字典](数据源与指标字典.md)。看板服务无法打开、连接失败或筛选结果异常时，向维护者提供页面名称、筛选值和查询时间。 [部署与运维手册](部署与运维手册.md)
