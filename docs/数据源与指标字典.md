# 数据源与指标字典

项目使用阿里云天池发布的天猫电商用户行为与复购历史数据。摄取程序读取格式一的三份 CSV。 [阿里云天池 原始数据集](https://tianchi.aliyun.com/dataset/42) · [IJCAI 复购买家预测竞赛说明](https://ijcai-15.org/repeat-buyers-prediction-competition/)

## 输入和质量规则

| 文件 | 一行代表 | 源字段 |
|---|---|---|
| `user_log_format1.csv` | 一条用户行为 | `user_id` 用户、`item_id` 商品、`cat_id` 类目、`seller_id` 商家、`brand_id` 品牌、`time_stamp` 月日、`action_type` 动作 |
| `user_info_format1.csv` | 一个用户的画像 | `user_id` 用户、`age_range` 年龄组编码、`gender` 性别编码 |
| `train_format1.csv` | 一对有标签的用户和商家 | `user_id` 用户、`merchant_id` 商家、`label` 复购训练标签 |

- 动作 `0` 为点击、`1` 为加购、`2` 为购买、`3` 为收藏。标签 `1` 为正样本，`0` 为负样本。商家在两份文件中的字段名分别是 `seller_id` 和 `merchant_id`，加工后统一为 `merchant_key`。
- 全量行为分析范围为 `0511–1111`。月日从 `0511` 转为连续日序，日序 1 对应 `0511`。全量任务载入行为文件并校验列。原始层保留文本值及行号，第一条数据记录的行号为 2。
- 日序超出窗口或动作码无效的原始记录进入隔离视图。已核验 46 条隔离记录均为 `1112`。品牌无法转为整数时归入未知键 `0`。年龄组 `0` 或空值归为未知，其他编码原样保留。性别编码 `0` 为女性、`1` 为男性，其余归为未知。没有独立业务事件号，计数沿用源记录粒度及源行号。
- 全量行为原始层 54,925,330 条，有效明细 54,925,284 条，覆盖 4,995 个活跃商家。全量用户画像 424,170 行，训练标签 260,864 对。样本运行只加载 `0511`、`0512` 共 40,748 条行为，画像按样本行为涉及的用户取子集，训练标签仍加载完整范围。7 日回访由全量批次生成。

## 指标口径

| 指标 | 计算口径 | 读数提示 |
|---|---|---|
| 活跃用户数 | 对给定商家和日期范围内发生任一有效行为的 `user_key` 精确去重 | 日报按单天统计。算同一商家跨日活跃须从商家用户日表重新去重。合计多个商家时，同一用户可能按商家重复计入 |
| 购买用户数 | 在同一商家和日期范围内发生至少一次购买行为的人数，按用户精确去重 | 一位用户多次购买仍计一人 |
| 购买用户占比 | 同一商家和日期范围内的购买用户数 ÷ 活跃用户数 | 分母为零时无可读比率。商家 `3828` 的 `0511` 为 70/184，约 38.04% |
| 行为数、购买行为数 | 有效行为记录计数、动作码为 `2` 的记录计数 | 一人多次行为可贡献多条记录。购买行为数包含在行为总数中 |
| 用户分群日活跃 | 按月日、年龄组、性别对用户去重 | 跨日期合计解释为日活跃人次 |
| 商家 7 日回访率 | 当日活跃用户中，次日到第七日内再次与同商家互动的人数 ÷ 当日活跃用户数 | 只取后续七个自然日都在观察范围内的起算日，最后可用起算日为 `1104`。商家 `3828` 的 `0511` 为 32/184，约 17.39%。汇总多个观察日先分别合计分子与分母 |
| 样本复购比例 | 正标签的用户与商家组合数 ÷ 有效标签组合数 | 全训练标签中为 15,952/260,864，约 6.12%。按商家筛选时，分子分母同时限制到该商家 |

7 日回访用历史行为日志判定同商家的后续互动，其中包括点击、加购、购买、收藏。复购比例用竞赛训练标签，原任务考察大促新买家半年内是否再次向同一商家购买。二者的观察期与样本各有定义。 [IJCAI 复购任务定义](https://ijcai-15.org/repeat-buyers-prediction-competition/)

## 指标目标与验收记录

指标核验脚本 `scripts/validate_full.py` 可通过 `--targets` 读入目标配置。可用键为 `active`、`purchase`、`return7`、`repeat`，人数用非负值，比率用 0 至 1。无业务目标时状态为「未设定」。趋势以等长、可比较的观察窗口做对照。只有单个标签窗口时复购没有可比前期。

商家 `3828` 在 `0511` 有 272 条行为、184 位活跃用户和 70 位购买用户，已用 DWD 明细、ADS 日报和看板筛选交叉核对。读数与操作办法见[看板操作手册](看板操作手册.md)。
