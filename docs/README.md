# 电商商家与用户运营数仓文档

本项目将天猫公开历史样本加工为离线数仓，提供商家运营、类目品牌、用户回访与样本复购看板。运营人员可以直接查询看板，数据工程人员可以追溯明细并维护数据发布。

| 文档 | 内容 |
|---|---|
| [需求分析说明书](需求分析说明书.md) | 业务背景、用户场景、功能与非功能需求、验收标准 |
| [数据源与指标字典](数据源与指标字典.md) | 输入文件、日期和标签范围、指标算法及示例 |
| [数仓设计说明书](数仓设计说明书.md) | 数据流、事实与维度、分层存储、批次和发布 |
| [部署与运维手册](部署与运维手册.md) | 本机启动、验证、发布、重跑与故障排查 |
| [看板操作手册](看板操作手册.md) | 三个看板、筛选操作、读数与明细回查 |

第一次使用看板，可以从商家 `3828` 在 `0511` 的日报入手。该日有 272 条行为、184 位活跃用户、70 位购买用户。数据文件由使用者从[阿里云天池](https://tianchi.aliyun.com/dataset/42)获取。
